---
title: Downloads
description: How missing tracks are fetched and added to the library.
---

Missing tracks are downloaded automatically via the following providers:

1. [slskd](https://github.com/slskd/slskd) if `SLSKD_URL` and `SLSKD_API_KEY` are set.
2. [yt-dlp](https://github.com/yt-dlp/yt-dlp) as a fallback.

Downloaded files are placed in `DOWNLOAD_DIR` and the music server library is rescanned immediately after.

<Callout>
`DOWNLOAD_DIR` should match the library path your music server scans, otherwise downloaded tracks will never show up. See [Configuration](/docs/configuration).
</Callout>

## How it works

See [Download pipeline](/docs/concepts/downloads-pipeline) for the full flow: slskd first with YouTube fallback, post-download tagging, and file layout.

The dashboard header shows whether slskd is configured and reachable. Non-`flac` files are upgraded to lossless on a later sync when slskd is configured.
