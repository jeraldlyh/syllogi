Browse globally trending tracks. Tracks can be queued for [download](/docs/features/downloads) directly from the Charts tab, and the download activity log on the dashboard tracks the status of all in-progress and completed downloads.

Trending tracks uses Last.fm when `LASTFM_API_KEY` is set, otherwise falls back to Deezer. Each track shows whether it already exists in your library.

## Search and browse

- Typing a few characters switches the view to Search Results covering artists and tracks.
- Toggle List/Grid view and refresh manually.
- Clicking a track's artist opens the artist drawer (bio, stats, discography, top tracks with library counts); clicking the album opens the album drawer (cover, release, per-track download status).
