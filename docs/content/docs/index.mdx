**syllogi** is a self-hosted automation tool that keeps your [Jellyfin](https://github.com/jellyfin/jellyfin) or [Navidrome](https://github.com/navidrome/navidrome) music library in sync with external playlists from Spotify and YouTube.

It matches tracks against your indexed audio, automatically downloads missing tracks via [yt-dlp](https://github.com/yt-dlp/yt-dlp) or [slskd](https://github.com/slskd/slskd), generates personalized recommendations based on your listening history, and lets you browse trending charts, all from a single dashboard.

## Supported playlist providers

| Provider    | Requirements                                                                                        |
| ----------- | --------------------------------------------------------------------------------------------------- |
| **Spotify** | No API key or account needed, public playlists only, via [SpotAPI](https://github.com/Aran404/SpotAPI) |
| **YouTube** | No API key needed, public playlists only, via [yt-dlp](https://github.com/yt-dlp/yt-dlp)            |

## Supported music servers

| Server        | Requirements                                           |
| ------------- | ------------------------------------------------------ |
| **Jellyfin**  | API key with permission to create and manage playlists |
| **Navidrome** | URL, username, and password |

## Caveats

<Callout type="warn" title="Before you start">
- Matching depends on metadata quality from the provider and music server.
- Library refresh timing can delay newly downloaded tracks.
- A restart invalidates in-flight SSO logins.
</Callout>
